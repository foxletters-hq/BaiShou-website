title: 白守是什么

---

白守是一款开源的、本地优先的 AI 记忆陪伴软件。

你在本地写下日记和生活片段，白守把它们逐层总结成「回忆年轮」，再交给 AI 伙伴长期理解、检索和陪伴。数据不进某个云端账号，留在你自己的设备上。

> 以纯白誓约，守护彼此一生。

## 它能做什么

| 能力 | 说明 |
|------|------|
| 日记 | Markdown 书写，可记天气、心情、标签、位置，支持附件 |
| 回忆年轮 | 日记逐层总结成周记、月报、季报、年鉴 |
| AI 伙伴 | 多个伙伴，各自有人格和模型，能调用工具读写日记与记忆 |
| RAG 语义记忆 | 向量检索加全文检索，让伙伴真的搜得到你写过的细节 |
| 工作空间 | 多个工作区，数据彼此隔离 |
| 同步与备份 | 增量同步、全量备份、局域网传输，桌面端还有 Git 版本控制 |

:::note[文件知识库还没做完]
官网提到的文件知识库（PDF、DOC 等本地文档）仍在开发中。当前版本请以日记和回忆为主。
:::

## 和 Notion、Obsidian 有什么不一样

笔记工具解决的是「资料放得整齐」，白守想解决的是「AI 真的记得你」。

| | 笔记工具 | 白守 |
|--|----------|------|
| 重心 | 整理、双链、写作 | 被 AI 长期理解和使用的个人记忆 |
| AI | 多是插件或外挂的对话框 | 伙伴、回忆年轮、RAG 就是产品骨架 |
| 数据 | 常依赖官方云或插件生态 | 默认在本地，可选同步到你自建的 S3 / WebDAV |

## 我们坚持的几件事

1. **本地优先**：核心数据在你的设备上，随时能导出、能带走。
2. **核心能力开放**：日记、自建同步、自定义模型 API 不设付费墙。
3. **让 AI 读懂你的资料**：能检索、能问答、能总结，而不只是个网盘。
4. **官方服务只是选项**：想省事可以用，不付费同样能完整使用。
