增量同步用来在你的设备和自建云（S3 或 WebDAV）之间，按文件做增量对齐。改了哪些传哪些，不是整包搬。

## 怎么跑一次

1. 配置远端：端点、桶或路径、密钥。
2. 点 **预览计划**，看清这次会动哪些文件。
3. 确认没问题再执行同步。

第一次用之前，建议把客户端内的同步说明和风险提示读一遍。

同步范围通常包括日记、回忆总结、会话、伙伴、附件、部分设置目录，以及工作区注册信息。

:::caution[和全量备份不是一套]
- 云路径默认是分开的，增量常用 `memories_sync` 这类目录。
- 覆盖范围也不同，是否包含完整数据库和向量缓存不一样。
- 千万不要把两套功能指向同一个目录，然后交叉覆盖。

区别详见 [三种方式怎么选](/docs/sync/overview/)。
:::

## 分端建议

桌面端可以放心双向，同时建议开着 [Git 版本控制](/docs/advanced/desktop/) 方便回滚。

移动端网络和权限都更脆，务必先看预览计划。遇到冲突先备份再同步。

另外别让各端应用版本差得太远，容易出奇怪的问题。

## 密钥会跟着走

如果同步范围包含设置目录，API Key 就可能进到云端。请限制那个桶或目录的访问权限，也别在不可信的设备上把完整配置拉下来。
